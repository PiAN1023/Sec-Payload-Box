# Web安全Payload速查工具箱

## 一句话介绍

一款完全离线的浏览器安全测试 Payload 速查工具，内置 14 大类、312 条 Web 安全 Payload，支持全文检索、收藏、自定义、批量管理、6 种编解码和 JSON 备份，适用于授权渗透测试、护网、CTF 与安全学习。

## 工具定位

Web安全Payload速查工具箱是一款运行在 Chrome/Edge 浏览器扩展弹窗中的本地速查工具。它把日常 Web 安全测试中高频使用的 Payload 按漏洞类型和利用场景整理成卡片，打开扩展即可搜索、复制和编码，不需要切换网页、不需要登录账号，也不依赖外部服务。

工具重点解决三个问题：

- **查得快**：按分类浏览，或直接搜索 Payload、场景说明、细分标签和分类名。
- **带得走**：常用 Payload 可以收藏，个人常用的测试语句可以新增为自定义 Payload。
- **改得动**：支持自定义分类、编辑、删除、批量删除、复制整类内容和 JSON 导入导出。

## 核心功能

### 1. 内置 312 条 Payload，覆盖 14 类 Web 安全场景

每条 Payload 都包含分类、细分场景、中文场景说明和 Payload 内容，既可以直接复制，也可以先看说明再判断适用条件。

| 分类 | 条数 | 主要内容 |
|---|---:|---|
| SQL 注入 | 27 | MySQL、MSSQL、Oracle、PostgreSQL、SQLite；联合查询、报错、布尔盲注、时间盲注、堆叠注入、宽字节与 WAF 绕过 |
| XSS 跨站脚本 | 28 | 反射型、存储型、DOM 型；属性闭合、事件注入、SVG、CSP 绕过、Cookie 读取与外带 |
| SSRF 服务端请求伪造 | 23 | 内网探测、file 协议、云元数据、Gopher、Redis、IP 进制与 URL 解析绕过 |
| 目录穿越 / 路径遍历 | 20 | Linux/Windows 路径、URL 编码、双重编码、Unicode 与截断变形 |
| 命令注入 | 29 | Linux/Windows 命令拼接、盲注与无回显、外带验证、编码与分隔符绕过 |
| 模板注入 SSTI | 24 | 常见模板引擎的探测、回显与命令执行思路 |
| 文件上传绕过 | 19 | 扩展名、MIME、文件头、内容检测、解析配置、.htaccess/.user.ini 与 SVG 上传等场景 |
| XXE 外部实体注入 | 18 | 本地文件读取、外部 DTD、Blind XXE、XInclude、XXE 触发 SSRF |
| 文件包含 | 20 | PHP 伪协议、日志包含、会话文件、远程包含与路径变形 |
| NoSQL 注入 | 18 | MongoDB 查询操作符、认证绕过、数组参数；Redis 未授权、写 Webshell、命令执行；Memcached |

| 反序列化 | 18 | PHP、Java、Python 常见反序列化链；Phar、Fastjson、Jackson、Shiro、Pickle、YAML 等场景 |

> 统计口径：当前版本共 312 条内置 Payload，每类均不少于 18 条。

### 2. 全文检索与关键词高亮

搜索范围覆盖：

- Payload 内容
- 场景说明
- 细分场景标签
- 所属分类

输入关键词后即时过滤，匹配内容会高亮显示；搜索状态下可以跨分类查看结果。按 **Ctrl+F** 可随时聚焦搜索框。

### 3. 收藏与快速复用

- 任意内置或自定义 Payload 都可以点击星标收藏。
- “我的收藏”分类集中展示常用内容。
- 收藏基于稳定的 Payload ID 保存，内置数据更新后仍可保留对应收藏关系。

### 4. 自定义 Payload 与分类

- 新增自定义 Payload，可指定分类、场景说明和 Payload 内容。
- 支持编辑、单条删除和批量删除自定义 Payload。
- 支持新建、重命名、删除自定义分类。
- 删除分类时可以选择是否同时删除该分类下的自定义 Payload。
- 内置 Payload 只读，避免误改；需要调整时可复制为自定义条目。

### 5. 一键复制与整类复制

- 单条 Payload 可一键复制，并显示成功或失败反馈。
- 可按当前分类复制全部 Payload，适合整理测试清单或迁移到其他工具。
- 复制内容保持原始换行和特殊字符，便于直接粘贴到 Burp Suite、浏览器地址栏或测试脚本中。

### 6. 六种编解码工具

内置独立编码工具，支持编码和解码：

- URL 编码
- HTML 实体
- Base64
- Unicode
- Hex
- JSON 转义

在 Payload 卡片上点击“编码”，可以把该条内容直接发送到编码工具；输出结果支持一键复制。Base64、Hex 等按 UTF-8 处理，支持中文和 Emoji。

### 7. 数据备份与恢复

- 将自定义 Payload、自建分类和收藏记录导出为 JSON 文件。
- 导入前会校验数据格式，格式错误不会修改现有数据。
- 支持“追加导入”和“覆盖原有自定义数据”两种模式。
- 内置 Payload 不参与导出，避免备份文件臃肿。

### 8. 快捷键

| 快捷键 | 功能 |
|---|---|
| Ctrl+F | 聚焦 Payload 搜索框 |
| Ctrl+Enter | 在编辑 Payload 时快速保存；在编码工具中快速执行编码 |
| Esc | 关闭当前弹窗；无弹窗时清空搜索；再次按下关闭扩展 |

## 适用场景

- **授权渗透测试**：快速查找 SQL 注入、XSS、SSRF、XXE、文件包含等验证语句。
- **护网与应急排查**：对照常见 Payload 特征，辅助判断告警和日志中的攻击行为。
- **CTF 与安全学习**：按漏洞类型系统浏览利用思路，理解不同数据库、框架和系统的差异。
- **安全开发自查**：开发人员了解常见危险输入形态，完善输入校验与输出编码。
- **安全培训与演示**：在隔离环境中展示常见 Web 漏洞的验证方法。
- **个人知识沉淀**：把团队常用测试语句整理成自定义分类，并通过 JSON 备份迁移。

## 数据与隐私

- 纯本地运行，不上传 Payload、搜索记录或收藏数据。
- 不包含远程脚本、外部样式、CDN 资源或统计代码。
- 不发起网络请求，断网环境可正常使用。
- 自定义数据保存在当前浏览器的扩展本地存储中，不会自动同步到其他设备。
- 仅声明 storage 与 downloads 权限；不申请主机权限，不注入页面，导出备份时使用 downloads 权限。
- 无后台服务、无内容脚本、无主机权限。

## 技术说明

- Manifest V3 扩展，弹窗式界面，适配 520×600 的浏览器扩展窗口。
- 原生 HTML、CSS、JavaScript 实现，无第三方框架和运行时依赖。
- 内置数据与界面代码打包在扩展内部，断网环境可正常使用。
- 浅橙色主题，Payload 使用等宽字体展示，长内容支持卡片内滚动。
- 支持 Chrome 88 及以上版本，Edge 等 Chromium 内核浏览器同样适用。

## 使用边界

本工具中的 Payload 仅用于**合法授权的安全测试、教学研究和防御验证**。请勿对未授权系统使用；部分命令执行、反序列化和文件读取 Payload 具有破坏性，应在隔离环境中验证。示例中的 evil.example、dnslog.example 等域名仅作占位，实际测试时请替换为自有可控地址，并遵守当地法律法规和测试授权范围。
