Sec Payload Box
web浏览器插件

Web安全Payload速查工具箱是一款面向授权安全测试场景的离线 Payload 速查扩展。它将日常 Web 安全测试中常见的验证语句整理为 312 条结构化卡片，覆盖 SQL 注入、XSS、SSRF、目录穿越、命令注入、模板注入、文件上传绕过、XXE、文件包含、NoSQL 注入、其他注入、权限绕过与信息泄露、反序列化、表达式注入等 14 类场景。

每条 Payload 都包含所属分类、细分场景、中文说明和具体内容。打开扩展后，可以按分类浏览，也可以直接搜索 Payload 内容、场景说明、细分标签或分类名，匹配结果会高亮显示。常用内容可以收藏到“我的收藏”，也可以复制单条 Payload 或复制当前分类下的全部内容。

工具支持完整的数据管理：可以新增、编辑、删除自定义 Payload，新建、重命名、删除自定义分类，批量删除自定义内容；自定义分类、Payload 和收藏记录可以通过 JSON 文件导出，并在其他环境中追加导入或覆盖导入。内置 Payload 保持只读，避免误修改。

除 Payload 库外，工具还提供 URL、HTML 实体、Base64、Unicode、Hex、JSON 转义 6 种编解码方式，支持编码和解码，并可将 Payload 卡片内容直接发送到编码工具。常用快捷键包括 Ctrl+F 聚焦搜索、Ctrl+Enter 快速保存或编码、Esc 关闭弹窗。

工具采用 Manifest V3，弹窗尺寸适配 520×600 的浏览器扩展窗口，使用原生 HTML、CSS、JavaScript 实现，无第三方框架和网络依赖。数据保存在浏览器本地，仅声明 storage 与 downloads 权限，不申请主机权限，不注入页面，断网环境也可正常使用。

适用人群包括渗透测试工程师、安全服务人员、护网与应急响应人员、安全开发与代码审计人员、CTF 选手及网络安全学习者。、

！！！所有 Payload 仅用于合法授权的安全测试、教学研究和防御验证，请勿对未授权系统使用；命令执行、反序列化和文件读取类 Payload 应在隔离环境中验证。！！！
